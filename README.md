# 🚀 Prince Portfolio

Modern personal portfolio website built with React.js and Tailwind CSS showcasing my projects, skills, and experience as a Full Stack Developer.

---

## 🔥 Features

- Modern UI with clean design
- Fully responsive (mobile + desktop)
- Projects showcase with modal view
- Skills, Experience & Education sections
- Download CV option

---

## 🛠️ Tech Stack

- React.js
- JavaScript
- Tailwind CSS
- HTML5 & CSS3

---

## 📂 Sections

- About
- Skills
- Projects
- Experience
- Education

---

## ⚙️ Installation

```bash
git clone https://github.com/Prince3636/Prince_Portfolio.git
cd Prince_Portfolio
npm install
npm run dev
